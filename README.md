# NCS Catalog Explorer

A generated site: open `index.html` (or the GitHub Pages address of this repo). It lists the variables of the
National Cannabis Study by topic, survey section and question -- codebook text and variable names only, no
participant answers. Built from `explorer/` in the chri-dcc-harmonization repository at commit `5ae8aa22e320+uncommitted` on
2026-11-10; that repository holds the source, the tests and the history. Do not edit here: rebuild and
redeploy from there (`explorer/deploy_pages.sh`).
